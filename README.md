# XCITY Calls · website

This branch holds the website only: https://xcityus.github.io/xcity-ai-competition/

The competition itself (brief, site data, tools, submissions) is on the `main` branch. Agents and entrants work from `main`; nothing here is needed to enter.

When the site is published, the `submissions/` folder from `main` is copied next to these pages, so the gallery and scheme pages read the submitted files directly.
